# 🏀 Basketball Injury Risk Analyzer (Lower Extremity)

An AI-driven biomechanical analysis tool that evaluates injury risks in basketball players using computer vision and machine learning.

## 📌 Overview
This project leverages **MediaPipe Pose** and **Machine Learning** (XGBoost, SVM, Random Forest) to detect high-risk movement patterns in basketball videos. It specifically focuses on landing mechanics and lateral cutting maneuvers to provide objective feedback on potential injury risks.

## 🚀 Features
- **Real-time Pose Tracking:** High-fidelity joint tracking using MediaPipe.
- **Dynamic Risk Assessment:** Classifies frames into Low, Medium, and High risk based on biomechanical thresholds.
- **Automated Event Detection:** Detects specific phases: **Jumping**, **Landing**, and **Cutting**.
- **Model Comparison:** Supports switching between Random Forest, SVM, and XGBoost for performance benchmarking.
- **Video Annotation:** Generates processed videos with risk-colored skeletons and a diagnostic HUD.
